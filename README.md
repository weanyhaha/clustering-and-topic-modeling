# Кластеризация и тематическое моделирование

Учебное исследование обучения без учителя на двух задачах: группировка остановок общественного транспорта Москвы и выделение тем в новостях BBC. В ноутбуке реализована спектральная кластеризация графа, сравниваются методы кластеризации и исследуется использование кластерных и тематических представлений для классификации текстов при ограниченной разметке.

## Реализовано

| Раздел | Содержание |
|---|---|
| Спектральная кластеризация | Собственный `GraphClustering`: лапласиан графа, собственные векторы, нормализация представлений и KMeans |
| Транспортный граф | Выделение маршрутов, эвристическое упорядочивание остановок по haversine-расстоянию, построение матрицы смежности |
| Кластеризация остановок | KMeans, DBSCAN и GraphClustering; подбор параметров через Optuna по silhouette score |
| Визуализация геоданных | Интерактивные карты Folium с остановками, маршрутами, кластерами и шумом |
| Подготовка текстов | Токенизация, лемматизация, удаление стоп-слов, TF-IDF и CountVectorizer |
| Тематическое моделирование | KMeans, DBSCAN, SpectralClustering и LDA; ключевые слова, облака слов и t-SNE |
| Классификация текстов | LogisticRegression на TF-IDF, расстояниях до центров KMeans и распределениях тем LDA; эксперименты с малой разметкой |

## Эксперименты и проверки

Результаты, сохранённые в ноутбуке:

- `GraphClustering` проверен на синтетическом графе из **10 блоков и 1000 вершин**;
- лучший silhouette score на координатах остановок: **0,4191** для KMeans, **0,3651** для DBSCAN и **0,2892** для GraphClustering; для DBSCAN метрика считается без шумовых точек;
- KMeans выделяет интерпретируемые группы новостей, а LDA с **20 темами** позволяет получить более узкие сюжеты.

Test accuracy классификации новостей:

| Представление | Полная обучающая разметка | Малая разметка |
|---|---|---|
| TF-IDF | **97,85%** | **87,07%** |
| Расстояния до центров KMeans | **81,69%** | **91,56%** |
| Распределения тем LDA | **92,46%** | **94,08%** |

В эксперименте с малой разметкой классификатор обучается на 5% обучающей части после выделения validation, а представления строятся с использованием неразмеченных текстов. Для этого эксперимента дополнительно подбираются параметры: результаты отражают и пользу неразмеченных данных, и влияние настройки моделей.

## Стек

Python, NumPy, pandas, scikit-learn, Matplotlib, Folium, Optuna, NLTK, WordCloud, openpyxl, JupyterLab.

## Запуск

Из каталога `clustering-and-topic-modeling`:

```bash
python -m pip install numpy pandas scikit-learn matplotlib folium optuna nltk wordcloud openpyxl jupyterlab
python -m nltk.downloader punkt punkt_tab wordnet stopwords
jupyter lab homework-practice-08-unsupervised.ipynb
```

Перед запуском положите рядом с ноутбуком два файла, которые не включены в каталог:

- `transport.xlsx` — данные остановок по ссылке из первой части ноутбука; для экспериментов отбираются остановки ЦАО;
- `bbc-news-data.csv` — корпус BBC News Archive по ссылке из второй части; файл читается с разделителем табуляции и должен содержать `category`, `title` и `content`.

Ссылки на источники данных приведены в ноутбуке. Для первоначальной загрузки ресурсов NLTK нужен интернет. Выполняйте ячейки последовательно: третья часть использует тексты, подготовленные во второй.
